# 小满学习台

给小学低年级孩子的学习练习工作台：**口算 + 语文听写 + 拼音 + 英语跟读**。纯前端单页应用，**零后端、零 API 成本、零依赖安装**——数据全部存在孩子设备本地。

一个真实的由来：给自家二年级孩子做的。孩子在 iPad 上练，家长只负责"核对 + 补录"，其余自动。设计上刻意做了几件"反直觉"的事，详见下面各模块说明。

- 在线实例：`https://learning.basisdiff.com`（国内直连，实测 0.5s）——**给自己孩子用，打开这个网址就够了**（iPad 上分享 → 添加到主屏幕）。想改造、换教材、自部署，往下看。

## 为什么没有服务器

出题是规则计算、判分是字符串比对、复习排期是本地日期运算——没有一条逻辑需要云端。所以后端整体移进了浏览器（`web/local.js`），数据存 localStorage。**Mac 不开机孩子也能用，没有账号，没有数据上传。**

## 孩子怎么用（iPad）

1. Safari 打开网址
2. 分享 → 添加到主屏幕（得到独立 App 图标）
3. 之后离线也能用（Service Worker 缓存，第一次打开需要联网）

数据存在这台 iPad 的浏览器里。**换设备或清 Safari 网站数据会丢**——家长面板底部有「备份到文件」，建议每周点一次。

## 功能

| 模块 | 说明 |
|---|---|
| 口算 | 三档难度（按孩子真实进度排，除法只进挑战档）：**简单**=两位数加减（含进位退位）+ 2~5 乘法；**适中**=100 以内加减（含进退位、100 减两位数）+ 全部口诀；**挑战**=连加连减、乘加乘减、除法、元角分 |
| 听写 | 统编版二上『词语表』239 词（8 单元 23 课），可听到「课」一级；**全程不显示答案**。孩子只有两个键：「写完了，下一个」和「不会，跳过」。对错不由孩子判——"写完了"是中性记录不计分，"不会"的词进待攻克；写没写对以**家长核对本子**为准（面板里有专门的核对入口） |
| 拼音 | 教材词 239 个 + 变调/轻声/多音字专项共 302 词条。两种题型：**选拼音**（四选一）和**变调判断**（读第几声）。专项：变调 / 多音字 / 前后鼻音 / 平翘舌 / 轻声，也能按单元/课出题。**机器判分，正确率是真的**（不像听写是自评） |
| 英语跟读 | **整句输出优先于背单词**：听原句（神经 TTS 英文儿童声）→ 录音跟读 → 回放自己的录音和原音对比 → 自评。8 个高频句型包 × 6 句。刻意**不用语音识别打分**——机器给儿童发音打分太苛刻，一句"不标准"就把开口意愿打没了；自己听自己，比一个分数有用 |
| 复习 | 错题按 **1/3/7/15/30 天**间隔重现（艾宾浩斯），连对 5 轮视为掌握。写字题是"听音 → 纸上写 → 揭晓答案 → 自评"；拼音题点选式，不用打字 |
| 家长面板 | **每天做了什么**（按时间一行一组，练习/复习/家长核对分得清清楚楚）、分题型正确率、**最快纪录**（同口径计时对比）、学校听写错词补录（点选即录）、待攻克清单、听写词表逐课编辑、备份/恢复/清空 |

### 出题不是随机的：记忆加权

听写和拼音的出题池按"记忆强度"加权抽取：刚错的词权重最高；最近答对的按间隔衰减（1/3/7/15 天递减）；**已掌握的降到最低档但不是零**（偶尔回来巩固）；没练过的中等（新词需要露面）。实测"昨天错的词"出现频率是"一个月前对的词"的 5 倍以上。

### 计时与最快纪录

做题时右上角走秒；一组做完和**同口径**（同科目、同难度、同题数、同范围）历史最快比，结果页给"🏆 新纪录 / 首次 / 没破"三种卡片。5 道题和 20 道题永远不会互比。

### 拼音的标音为什么可信

基础标音用 pypinyin，但**「一 / 不」变调由本项目按规则自己算**——pypinyin 在这里不可靠（`一个=yí` 对，`一天/一样/一起` 全错）。轻声、儿化、多音字是手工校对过的（`肚子 dù、告诉 gào su、妈妈 mā ma、一块儿 yí kuàir` 等）。

变调规则（生成时生效）：
- 「一」：后字四声读 yí（一个 yí gè）；后字一/二/三声读 yì（一天 yì tiān）；序数不变（第一 dì yī）
- 「不」：后字四声读 bú（不是 bú shì）；其余 bù
- **两个三声相连**：前一个字读二声，但**注音仍标本调**（小鸟 xiǎo niǎo）——所以这类词只出「读第几声」的题，不出「选拼音」，避免教错写法

干扰项也是设计过的：变调题放错的声调、多音字放另一种读音、鼻音专项放 an/ang 对调、平翘舌放 z/zh 对调、轻声放实调。全部规则生成，不是随机乱码。

### 听写发音

不用系统 TTS（单念双字词容易糊），**239 个词全部预生成神经 TTS 录音**（`web/audio/`，微软 Edge 神经音色、语速放慢，共约 3MB），每词自动连读两遍，听过的词缓存到设备离线可用。生成音频经过语音识别转写验证（勺子/转动/一块儿/告诉 全部准确识别）。家长面板加的课本外词没有录音，自动退回系统朗读。

词表数据源：人教社 2025 年秋季启用的新修订统编版（第三单元为《彩虹》《去外婆家》《数星星的孩子》）。换教材？改 `data/dictation.json` 重新生成就行（见下文）。

## 自部署

只是给孩子用？**直接用上面的在线实例**，不用部署。以下写给想自己搭一份的人（换教材、改题型、控制数据）。

### 方式一：拿到源码，纯本地打开（零门槛）

1. 本页右上角 **Code → Download ZIP**（或 `git clone https://github.com/sunshine2176/learning-desk.git`）
2. 解压，双击 `web/index.html`（Chrome/Edge/Safari 都行）
3. 结束。没有第 3 步。

局限：localStorage 按文件路径隔离，换了浏览器或挪了目录数据不跟走——当"一次性工具"没问题；想长期多设备用，走方式二。

### 方式二：部署到 Vercel（免费，推荐）

```bash
npm i -g vercel          # 装一次
vercel login
cd web                   # ← 必须在 web/ 里，否则传的是项目根目录（404）
vercel deploy --prod --yes
```

得到一个 `*.vercel.app` 域名，孩子设备直接用。想绑自己的域名：`vercel alias set <部署URL> 你的域名`（注意：`--prod` 发布新部署后 alias **不会自动跟过去**，要重跑一次 `alias set`）。改了任何 js 要把 `web/sw.js` 里的 `VERSION` 加一，否则设备吃旧缓存。

任何静态托管（Netlify / Cloudflare Pages / nginx）都行——`web/` 目录就是全部产物。

## 改词表 / 换教材

两种方式：

1. **设备上直接改**（推荐）：家长面板 → 听写词表 → 选到某一课 → 每行一个词 → 保存。
2. **改源文件**：编辑 `data/dictation.json` → `python3 tools/gen_dict.py` → `sw.js` 的 VERSION 加一 → 重新部署。

拼音题库同理：`data/pinyin.json`（真源）→ `python3 tools/gen_pinyin.py`。发音音频重新生成：`python3 tools/gen_audio.py`（需要 `pip install edge-tts`）。

```
│   ├── audio/           # 预生成发音（中文词 d*.mp3 + 英文句 e*.mp3）
│   ├── sw.js            # 离线缓存；改了页面把 VERSION 加一
│   └── manifest.json    # PWA 配置

├── tools/
│   ├── gen_dict.py      # 词表 json → dict.js
│   ├── gen_pinyin.py    # 拼音题库（变调规则 + 手工订正都在这）
│   ├── gen_english.py   # 英语句音频生成（edge-tts）
│   ├── gen_audio.py     # 中文词音频生成（edge-tts）
│   ├── pw.js            # playwright 解析器（env → npm → npx 缓存）
│   ├── test-local.js    # 数据层全链路测试
│   ├── test-pinyin.js   # 拼音模块测试
│   ├── test-ui.js       # 真实浏览器点击测试（Playwright，39 断言）
│   ├── check-*.js       # 专项验证：记忆加权/计时/学校错词/英语/发音/按课出题

```

```bash
python3 -m http.server 8899 --directory web    # 另开一个终端
node tools/test-local.js                       # 数据层：出题/判分/复习/词表
```

## 设计取舍（写给想改造的人）

- **孩子侧按键越少越好**：听写只剩"写完了 / 不会"两个键；一切需要孩子自评"对不对"的输入都不可信，对错判定要么机器判（拼音/口算），要么家长判（听写核对）。
- **机器不给儿童发音打分**：英语跟读用"录自己的音和原音对比"替代 ASR 打分，保护开口意愿。
- **计时只在同口径内比**：不同难度/题数的成绩比较没有意义，还会催生刷最简单档的动机。
- **学校听写错误不计入正确率**：不是在这台设备上做的题，只进复习队列，不污染统计。
- **所有数据在本地**：没有账号体系，没有上传，备份是家长手动导出 JSON 文件。
